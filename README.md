# Castle Empire

A Three.js castle kingdom game with:

- Four railway routes around the kingdom
- Two additional 3D airports
- Detailed surrounding buildings and city decoration
- A stone arch bridge and a suspension bridge
- Interactive 3D kingdom exploration

## Run

Open `index.html` in a browser, or serve the repository with any static web server. The game loads Three.js from its CDN URL, so internet access is required for the 3D engine.

## Controls

- Open the **Kingdom** view
- Drag to rotate or pan
- Pinch or scroll to zoom
- Explore the tracks, airports, bridges, and castle buildings
